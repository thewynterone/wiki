# Cómo unirse

Wolfland Network acepta jugadores de **Java** y de **Bedrock**.

| Edición | IP | Puerto |
|---------|----|--------|
| Java | `play.wolfland.pro` | por defecto |
| Bedrock | `play.wolfland.pro` | `19132` |

!!! info "Versión"
    Indica aquí la versión o rango de versiones compatibles.

## Entrar desde Java

1. Abre Minecraft Java con una versión compatible.
2. Ve a **Multijugador → Añadir servidor**.
3. En **Dirección del servidor** escribe `play.wolfland.pro`.
4. Pulsa **Listo** y entra al servidor.

## Entrar desde Bedrock (móvil, consola, Windows)

1. Abre Minecraft Bedrock.
2. Ve a **Jugar → Servidores → Añadir servidor**.
3. Rellena los datos:
    - **Nombre:** Wolfland Network
    - **Dirección:** `play.wolfland.pro`
    - **Puerto:** `19132`
4. Guarda y pulsa sobre el servidor para entrar.

!!! note "Consolas"
    En consolas (PlayStation, Xbox, Switch) no se puede añadir un servidor directamente. Hay que usar un método alternativo; consulta con el staff en nuestro [Discord](https://discord.com/invite/jCmngqZRFV).
